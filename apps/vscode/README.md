# 串口助手 · Serial Assistant（VS Code 扩展）

在 VS Code 里收发串口数据：HEX / 文本双视图、校验和、周期发送、发送预设、断线自动重连。

**一个面板 = 一条会话 = 一个端口。** 想同时盯两块板子，就开两个面板各连一个口，
互不干扰；同一个端口被另一个面板占着时会被直接拦下并说明原因，而不是给你一句
`Failed to open serial port` 让你猜。

## 用法

**最快的用法**：点左侧活动栏的 🔌 图标 → 看到机器上插着的端口 → **点一个就直接连上**。
命令面板 → 新建面板 → 选端口 → 打开，四步压成一步。

端口列表里已连上的口会标成绿色并注明「已连接」，点它会切到对应的面板而不是再开一个；
想同一个口再开一个面板，用行尾的 `+`。插拔设备列表会自己刷新。

其余入口：

- **状态栏**：右下角的 `🔌 串口`，点一下就新建。已经有面板时点它会列出全部面板，
  可以直接跳过去 —— 多面板时「我刚才那个 COM4 的面板跑哪去了」就靠它。
  嫌占地方可以用 `serialTool.statusBar` 设成仅在有面板时显示、或干脆隐藏。
- **编辑器标题栏**：焦点在串口面板上时右上角有个 `+`，就地再开一个连别的口。
- **命令面板**：「新建串口面板」/「串口面板…」/「刷新端口列表」。想要快捷键的话，
  在键盘快捷方式里给 `serialTool.newPanel` 绑一个即可（默认不占用任何组合键）。

面板里选端口、设波特率、打开。

## 与浏览器版的关系

同一套核心逻辑与界面，另有一份纯网页版（不需要安装任何东西，Chromium 系浏览器打开即用）。
扩展版多出来的是这些：

- 不需要每次手动授权端口，`COM3` / `/dev/ttyUSB0` 直接列出来；
- 设备身份带序列号，换个 USB 口插也认得出来，备注和波特率都跟着设备走；
- **串口连接活在扩展宿主进程里**：面板被隐藏、切去看代码，串口不会断，周期发送照跑；
- 设置存在 VS Code 的 globalState 里，可随 Settings Sync 跨机器同步。

## 已知限制

- 状态栏的「积压字节」暂未接通，恒为 0。
- 远程开发（SSH / WSL / 容器）时打开的是**扩展宿主所在那台机器**的串口。
